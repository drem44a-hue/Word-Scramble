**Word Scramble Luxury** هو نظام متطور لفك تشفير الكلمات، مصمم بواجهة سينمائية (Cyber-Luxury) ونظام حماية خارق. تم بناء المشروع ليكون تحدياً حقيقياً للعقل مع ميزات برمجية احترافية.

---

## 🚀 المميزات (Features)

* **🔒 نظام دخول مشفر:** دعم كامل لإنشاء الحسابات وتسجيل الدخول مع تشفير البيانات (Base64).
* **🎭 واجهة مستخدم ملكية:** تصميم زجاجي (Glassmorphism) مع تأثيرات بصرية جذابة.
* **📊 مستويات صعوبة ديناميكية:** (سهل، متوسط، صعب، مستحيل) مع كلمات معقدة ونادرة.
* **🏅 لوحة المتصدرين (Leaderboard):** نظام ترتيب حي لأفضل 5 لاعبين عالمياً (محلياً في المتصفح).
* **🛡️ حماية متطورة (Anti-Cheat):** نظام حماية يمنع استخدام أدوات المطور (F12) أو التلاعب بالنقاط.
* **⚙️ حساب المطور:** وصول خاص للمطورين لتجربة النظام بالكامل.

## 🛠️ التقنيات المستخدمة (Tech Stack)

* **HTML5:** للهيكل التنظيمي للعبة.
* **CSS3:** للتصميم والرسوم المتحركة المتطورة.
* **JavaScript (Vanilla):** لبناء المنطق البرمجي، نظام التشفير، وإدارة البيانات.
* **LocalStorage:** لحفظ سجل المتصدرين وبيانات اللاعبين بشكل دائم.
